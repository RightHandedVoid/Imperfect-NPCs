
Imperfect NPCs
=======
![I should probably put something here right?](./poster.png)

> "Custom NPCs is a mod to create NPCs to liven up worlds or to create your own adventure." - **Noppes\_** *Custom NPCs*

Imperfect NPCs is a spiritual successor to Noppes_'s CustomNPCs mod with the same thesis, but unlike
the original mod, Imperfect NPCs is meant to be a modern upgrade.
